## Key Technical Notes

- `textOnPrimary = #0F0F0F` (black) — Electric Green is LIGHT, never use as text on white
- `DSColors.accent = #7D9220` — only accessible green for text on white (4.6:1)
- `tailwind.config.js`: DSColors MUST be inlined — cannot `require('./src/theme/theme')` (TS ESM + Node = SyntaxError)
- Expo SDK 57: not supported by Expo Go — use Android emulator (Android Studio) or EAS dev build
- `StyleSheet.create + DSColors` for all new screens (NativeWind causes layout issues on maps)
- `VipHubsScreen` ITEM_HEIGHT = 108 (collapsed estimate) — `scrollToIndex` may need tuning after emulator test
