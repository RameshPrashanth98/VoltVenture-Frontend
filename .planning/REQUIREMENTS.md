# VoltVenture — v1 Requirements

## v1 Requirements

### Authentication

- [ ] **AUTH-01**: User can create an account with email and password
- [ ] **AUTH-02**: User can log in and stay logged in across app restarts
- [ ] **AUTH-03**: User can log out from the app
- [ ] **AUTH-04**: User can sign in via Google or Apple (social login)
- [ ] **AUTH-05**: User can reset their password via an email link

### Bike Discovery

- [ ] **DISC-01**: User can see available e-bikes near them on a map
- [ ] **DISC-02**: User can tap a bike to view its detail (battery %, price per minute, distance)
- [ ] **DISC-03**: User can filter bikes by battery level, price range, or bike type
- [ ] **DISC-04**: User can switch to a list view showing nearby available bikes

### Booking & Unlock

- [ ] **BOOK-01**: User can reserve a specific e-bike (on-demand or in advance)
- [ ] **BOOK-02**: User can unlock a bike by scanning its QR code via the app camera
- [ ] **BOOK-03**: User can unlock a bike via Bluetooth proximity
- [ ] **BOOK-04**: User sees a booking confirmation screen with pickup instructions

### Active Ride

- [ ] **RIDE-01**: User sees a live ride timer and running cost during an active session
- [ ] **RIDE-02**: User sees the current battery percentage of the rented bike
- [ ] **RIDE-03**: User sees their current location on a map during the ride
- [ ] **RIDE-04**: User can end the ride with one tap and proceed to payment

### Payments

- [ ] **PAY-01**: User is charged via their saved payment method when the ride ends
- [ ] **PAY-02**: User can add and manage payment methods (credit card or digital wallet)
- [ ] **PAY-03**: User receives a ride receipt with cost breakdown after each ride
- [ ] **PAY-04**: User can view ride history (list of past rides with date, duration, cost)

---

## v2 Requirements (Deferred)

- User can view and edit their profile (name, photo, language)
- User can manage notification preferences
- User can rate / review a bike after a ride
- User can see points or loyalty rewards
- Multi-language / localization support

---

## Out of Scope

- **Profile management (v1)** — edit name, photo, notification settings deferred to v2; not critical for first-time tourist flow
- **Fleet / operator dashboard** — separate product for bike operators; outside this app
- **Web version** — mobile-only (iOS and Android) for this milestone
- **Business / multi-rider accounts** — personal tourist use only; no organization-level features
