# Milestone v1.0: MVP

**Status:** SHIPPED 2026-08-18
**Phases:** 1-4
**Total Plans:** 16

## Overview

VoltVenture v1.0 MVP delivers the complete tourist e-bike rental flow from app open to active ride and payment. All four phases were executed as a frontend-only vertical slice with mocked/stubbed backend services. The app covers auth, bike discovery, booking and unlock, active ride, payment, and account management.

## Milestone Summary

**Key Decisions:**

- DSColors inlined in `tailwind.config.js` — cannot `require('./src/theme/theme')` (TS ESM + RNP import = SyntaxError in Node.js/jiti)
- textOnPrimary = #0F0F0F (black) — Electric Green (#C6FF2D) is LIGHT (1.36:1 contrast on white)
- accent = #7D9220 — only accessible green for text on white (4.6:1 contrast ratio)
- Social auth Phase 1: getMockGoogleToken() mock — real GoogleSignin deferred (requires dev build + OAuth)
- signOut() does NOT delete has_registered — returning users see Login, not Onboarding
- StyleSheet.create with DSColors for map/complex screens (NativeWind causes layout issues)
- BookingStack and RideStack registered as modal siblings in RootNavigator (not nested in conditional block)
- useRef epoch anchor for countdown/count-up timers — prevents drift vs decrementing counter
- End Ride: raw TouchableOpacity (#E53935) not PrimaryButton — green CTA and red destructive action visually distinct
- rideHistory in-memory array (resets on restart) — acceptable for mock/stub scope
- PAY-02 view-only per D-16 — real card entry deferred to backend integration

**Issues Resolved:**

- tailwind.config.js SyntaxError from require() — fixed by inlining DSColors
- Gradle OOM on Android build — fixed by Xmx1024m + x86_64 only architecture
- ANDROID_HOME / JAVA_HOME not set — documented setup: D:\Android\Sdk + D:\Program Files\Android\Android Studio\jbr
- Countdown timer memory leak — clearInterval in useEffect cleanup confirmed on all timer screens

**Issues Deferred:**

- UAT: Expo SDK 57 incompatible with published Expo Go; requires Android emulator or EAS dev build
- Fonts: Manjari (display) + Inter (body) not loaded — system fonts used; TODO in App.tsx (D-12)
- Google Maps Android API key: placeholder in app.json — must be obtained before device build
- Real Google/Apple OAuth: getMockGoogleToken() mock — requires dev build + Google Cloud Console setup
- Real BLE unlock: 3-state mock only — requires native BLE library integration
- Payment method management: Add card UI stubs to Snackbar — real card entry deferred to backend phase

**Technical Debt Incurred:**

- All backend services (authService, bikeService, bookingService, rideService, paymentService) are mocked/stubbed — full backend integration is the next major milestone
- In-memory rideHistory resets on app restart — needs persistent storage in backend integration
- Error/destructive colors (#D32F2F / #B00020) are placeholders — DS v0.1 explicitly notes status colours are missing; needs brand decision
