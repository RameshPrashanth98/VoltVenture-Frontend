<threat_model>
**Threats addressed in this plan:**

| Threat ID | Category | Component | Disposition | Mitigation |
|-----------|----------|-----------|-------------|------------|
| T-01-SC | Tampering | npm package installs | mitigate | All 13 packages verified against npm registry and source repos in RESEARCH.md Package Legitimacy Audit. No [SLOP] or [SUS] findings. Developer should verify source repos before first install. |
| T-01-01 | Information Disclosure | auth_token storage | mitigate | expo-secure-store (OS keychain: iOS Keychain Services, Android Keystore) — never AsyncStorage. Token stored only via SecureStore.setItemAsync. |
| T-01-02 | Elevation of Privilege | Navigator access guard | mitigate | AppTabs only renders when userToken != null in RootNavigator. Auth state cannot be spoofed from within the app — useReducer dispatch is the only mutation path. |
| T-01-03 | Information Disclosure | Password logging | mitigate | All TextInput password fields must use secureTextEntry={true}. No password value ever passed to console.log or error reporters. |
| T-01-04 | Tampering | SplashScreen timing | accept | Splash hide is gated on both font load and auth bootstrap completion — cannot be bypassed from user input. Low-risk: worst case is UI flash, not a security event. |

**Out of scope for this plan:** Token validation (handled in Plans 01-03, 01-04), social auth token spoofing (Plan 01-05), session fixation (Plans 01-03/04), brute force (mock layer only — real mitigation at backend in future phase).
</threat_model>
