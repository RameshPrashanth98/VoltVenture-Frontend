# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: tailwind-config-inline — DSColors MUST be inlined in `tailwind.config.js`; cannot `require('./src/theme/theme')` due to TS ESM + RNP import SyntaxError in Node.js/jiti. Always inline token values directly.
- [ ] CONSTRAINT: expo-sdk-57-go-incompatible — Expo SDK 57 is NOT supported by published Expo Go. App must be run on Android emulator (Android Studio) or via EAS dev build.
- [ ] CONSTRAINT: textOnPrimary-is-black — `textOnPrimary = #0F0F0F` (black). Electric Green (#C6FF2D) is LIGHT (1.36:1 contrast on white). Never use Electric Green as text on white backgrounds. For green text on white, use `accent = #7D9220` (4.6:1 contrast).

**Do not proceed until all boxes are checked.**
