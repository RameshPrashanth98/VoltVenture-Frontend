## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AsyncStorage read (settings keys) | Device-local storage; values are controlled strings, no external input |
| AsyncStorage write (settings keys) | App-internal selection values — bounded to known options; no free-text user input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-07 | Tampering | AsyncStorage settings values | accept | Values are app-controlled strings ('km'/'mi', 'Standard'/etc.); no user free-text; attacker with device access can modify AsyncStorage but gains only cosmetic preference change |
| T-05-08 | Information Disclosure | AsyncStorage preference keys | accept | Keys store only display preferences; no PII; no auth material |
| T-05-09 | Denial of Service | AsyncStorage read failure on mount | mitigate | All reads in try/catch with silent fallback to in-session defaults; screen renders correctly even if AsyncStorage is unavailable |
</threat_model>
