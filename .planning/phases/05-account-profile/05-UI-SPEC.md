# Phase 5 — UI Design Contract: Account & Profile

> Visual and interaction contract for Phase 5 screens: ProfileScreen, EditProfileScreen, SettingsScreen, PreferencesScreen, and AccountScreen header update.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (React Native — shadcn not applicable) |
| Preset | not applicable |
| Component library | React Native Paper (MD3LightTheme, via `paperTheme` in `theme.ts`) |

## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Between label and secondary text within a row |
| md | 16px | Row `paddingVertical`, internal card padding |
| lg | 24px | Section `paddingHorizontal`, title `paddingTop` |
| xl | 32px | Large avatar top margin on ProfileScreen |
| 2xl | 48px | Bottom safe-area padding buffer |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Avatar circle: 80px diameter (touch-target exception; not a spacing multiple but a standard mobile avatar size)
- Menu row minimum touch target: 52px height (accessibility minimum — same as PrimaryButton `minHeight`)

> Source: `AccountScreen.tsx` existing paddingHorizontal: 24, paddingVertical: 16; `PrimaryButton.tsx` minHeight: 52

## Typography

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Body | 15dp | 400 | 22dp (1.47) | Inter | Menu row labels, profile field values, toggle labels |
| Label | 13dp | 600 | 16dp (1.23) | Inter | Section headers above groups, caption text ("Member since") |
| Heading | 20dp | 600 | 26dp (1.3) | Inter | Screen titles (ProfileScreen "Profile"), avatar name |
| Display | 24dp | 600 | 30dp (1.25) | Inter | "Account" title on AccountScreen — existing pattern |

> Source: `DSTypography` in `theme.ts` (`body: 15/22/400`, `heading: 20/26/600`, `label: 13/16/600`); `AccountScreen.tsx` title `fontSize: 24` — weight collapsed to 600 to keep type scale at 2 weights (400 + 600)

Note: AccountScreen title (24dp/600) is a one-off inherited from Phase 1. All four new screens use `heading` (20dp/600) as their screen title style.

## Color

| Role | Hex | Usage |
|------|-----|-------|
| Dominant (60%) | `#FFFFFF` (`DSColors.background`) | Screen backgrounds for all 5 screens |
| Secondary (30%) | `#FAFAFA` (`DSColors.surface`) | Menu rows, toggle rows, settings rows, avatar placeholder fill |
| Accent (10%) | `#7D9220` (`DSColors.accent`) | "Edit" header button text; "Save Changes" success label; section group header text |
| Destructive | `#B00020` (`DSColors.destructive`) | "Discard Changes" confirmation action label only |

Accent (`#7D9220`) reserved for:
1. "Edit" navigation button in ProfileScreen header-right
2. Section group labels in SettingsScreen and PreferencesScreen (e.g., "GENERAL", "NOTIFICATIONS")
3. Active selection indicator text in segmented unit/map-style pickers

Do NOT use `DSColors.primary` (`#C6FF2D` Electric Green) as text on white surfaces — it fails contrast (1.36:1). Green is background-only.

Borders: `#EBEBEB` (`DSColors.border`) — `borderTopWidth: 1` on every menu row and toggle row.

Status colors:
- Error text: `#D32F2F` (`DSColors.error`) — inline field validation on EditProfileScreen name input
- Destructive action label: `#B00020` (`DSColors.destructive`) — Discard Changes dialog confirm button

> Source: `theme.ts` DSColors; MEMORY.md contrast notes; `AccountScreen.tsx` existing menuRow border pattern

## Screen Inventory

### AccountScreen (updated — not new)
- Prepend a profile header block above existing menu rows
- Header block: 80px avatar circle (initials "JT" on `DSColors.surface` background with `DSColors.textPrimary` text) + name (Heading, 20dp/600) + email (Body, 15dp/400, `textSecondary`) aligned center
- Header block `paddingVertical: 24`, `paddingBottom: 16`
- Tapping anywhere on the header block navigates to `ProfileScreen`
- Existing rows (Ride History, Payment Methods, Log Out) are preserved below

### ProfileScreen (new — view-only)
- Header: "Profile" title (Heading 20dp/600), "Edit" text button top-right (accent color `#7D9220`)
- Avatar: 80px circle, centered, `marginTop: 32`
  - If `avatarUri` is null: initials circle (`#FAFAFA` fill, `textPrimary` initials text at 24dp/600)
  - If `avatarUri` is set: `Image` with `borderRadius: 40`, `width: 80`, `height: 80`
- Name below avatar: Heading 20dp/600, `textPrimary`, centered, `marginTop: 16`
- Email below name: Body 15dp/400, `textSecondary`, centered, `marginTop: 4`
- "Member since" row: Label 13dp/600 text "MEMBER SINCE" (accent color, uppercase) + Body 15dp/400 date value — displayed as a labeled field row `marginTop: 32`, `paddingHorizontal: 24`
- Section border: `borderTopWidth: 1, borderColor: DSColors.border` above the field row group

### EditProfileScreen (new)
- Header: "Edit Profile" title (Heading 20dp/600), no right button
- Avatar: 80px circle, centered, `marginTop: 24`, overlaid with camera icon badge (`#FAFAFA` circle, 24px, `MaterialCommunityIcons name="camera"`, positioned bottom-right of avatar)
  - Tapping avatar opens `expo-image-picker` gallery picker
- Name input: React Native Paper `TextInput` below avatar, `marginTop: 24`, `paddingHorizontal: 16`
  - Label: "Display Name"
  - Mode: `outlined`
  - Error state: inline red text (`DSColors.error`) "Name can't be empty" beneath field
- "Save Changes" button: `PrimaryButton` at bottom, `marginHorizontal: 24`, `marginBottom: 24`
  - Label: "Save Changes"
  - Triggers in-memory profile state update and navigates back to ProfileScreen
- Discard Changes dialog: triggered on back navigation if unsaved edits exist
  - `Portal > Dialog` pattern (same as AccountScreen logout dialog)
  - Title: "Discard Changes?"
  - Body: "Your edits haven't been saved. Go back without saving?"
  - Actions: "Keep Editing" (dismiss) | "Discard" (`textColor: DSColors.destructive`)

### SettingsScreen (new)
- Header: "Settings" (Heading 20dp/600)
- Section group label: "GENERAL" — Label 13dp/600, `DSColors.accent`, `paddingHorizontal: 24`, `paddingTop: 24`, `paddingBottom: 8`
- Rows (menu row pattern from AccountScreen):
  - "Distance Units" — current value shown as secondary label right-aligned (`textSecondary`, 13dp/400), chevron-right
    - Tapping opens inline segmented picker below row (not a new screen): "km" | "mi"
  - "Map Style" — current value right-aligned: "Standard" | "Satellite" | "Dark"
    - Tapping opens inline segmented picker below row
  - "Language" — current value right-aligned (e.g., "English")
    - Tapping opens inline segmented picker below row: "English" | "Thai" | "Japanese"
- "Preferences" row (navigates to PreferencesScreen): icon `tune-variant`, label "Notifications", chevron-right
- All rows: `paddingHorizontal: 24, paddingVertical: 16, borderTopWidth: 1, borderColor: DSColors.border, backgroundColor: DSColors.surface`

### PreferencesScreen (new)
- Header: "Notifications" (Heading 20dp/600)
- Section group label: "NOTIFICATION CATEGORIES" — Label 13dp/600, `DSColors.accent`
- Toggle rows using React Native Paper `Switch`:
  - "Ride Alerts" — toggle; description: "Unlock confirmations and ride end summaries" (`textSecondary`, 13dp/400)
  - "Promotions" — toggle; description: "Discounts and VoltCoins earn events"
  - "System" — toggle; description: "App updates and account security alerts"
- Toggle row layout: icon (`MaterialCommunityIcons`, 20px, `textPrimary`) + `View` (label + description) + `Switch` right-aligned
- Toggle row: `paddingHorizontal: 24, paddingVertical: 16, borderTopWidth: 1, borderColor: DSColors.border, backgroundColor: DSColors.surface`
- Switch active color: `DSColors.primary` (`#C6FF2D`) — this is a background element, foreground track is automatically handled by RN Paper

> Source: CONTEXT.md D-09 navigation decision; D-06 photo picker; code_context established patterns; `DSColors` tokens

## Accessibility

- All `TouchableOpacity` menu rows must have `accessibilityRole="button"` and `accessibilityLabel` matching visible label text
- Avatar `TouchableOpacity` on AccountScreen: `accessibilityLabel="View profile for {name}"`
- Avatar on EditProfileScreen: `accessibilityLabel="Change profile photo"`, `accessibilityRole="button"`
- `Switch` components must have `accessibilityLabel` set to toggle label name (e.g., "Ride Alerts notifications toggle")
- Minimum touch target: 52px height on all interactive rows (enforced by `paddingVertical: 16` on 20dp text rows = ~52px total)
