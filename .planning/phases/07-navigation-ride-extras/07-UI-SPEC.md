# Phase 7 — UI Design Contract: Navigation & Ride Extras

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | React Native Paper (official) — no shadcn, no web registry |
| Preset | not applicable |
| Component library | React Native Paper (MD3) |
| Icon library | @expo/vector-icons — MaterialCommunityIcons (primary), Ionicons (fallback) |
| Font | System default (Manjari + Inter deferred from v1.0; system font in use) |

Registry Safety: React Native Paper is an official maintained library. No third-party registry. Safety gate not required.

## Spacing Scale

Declared values (React Native dp, multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Icon-to-label gaps, inline micro-padding |
| sm | 8dp | Chip gaps, handle bar margin, list item row internal gap |
| md | 16dp | Screen horizontal padding, card internal padding, header height gap |
| lg | 24dp | Card paddingHorizontal, section bottom margin, checklist item vertical padding |
| xl | 32dp | Screen top spacing (below safe area on non-map screens) |
| 2xl | 48dp | Receipt icon top margin, hero spacing |
| 3xl | 64dp | Not used in this phase |

Exceptions:
- ETA card top offset: `insets.top + 8dp` (follows ActiveRideScreen overlay pattern)
- End-ride / "Start Ride" button bottom offset: `insets.bottom + 16dp`
- Custom header height: fixed at 56dp (back icon 24dp + centred title + 40dp spacer)
- Touch targets: minimum 44dp tap area for checklist rows and charger info card CTA

## Typography

Based on DSTypography tokens from `src/theme/theme.ts`:

| Role | Token | Size | Weight | Line Height | Usage in Phase 7 |
|------|-------|------|--------|-------------|-------------------|
| Body | `DSTypography.body` | 15dp | 400 | 22dp | WalkingDirections step text, checklist item labels, charger info card body |
| Label | `DSTypography.label` | 13dp | 600 | 16dp | ETA card secondary line ("X min walk — Y m"), section overlines, distance badge |
| Heading (md) | `DSTypography.headingMd` | 17dp | 600 | 24dp | ETA card bike/charger name, custom header title, charger info card name |
| Heading | `DSTypography.heading` | 20dp | 600 | 26dp | SafetyMount screen title ("Safety Check") |
| Display | `DSTypography.display` | 32dp | 700 | 36dp | Not used in this phase |

Notes:
- ETA time display ("8 min walk"): 17dp / 600 / textPrimary — uses headingMd token
- ETA distance display ("620 m"): 13dp / 600 / textSecondary — uses label token
- Checklist item checked state: 15dp / 400 — strikethrough is NOT applied; use accent (#7D9220) color change only
- WalkingDirections step distance: 13dp / 600 / textSecondary (label token)
- All map-overlay text uses white (#FFFFFF) regardless of light DS convention, because overlay is dark

## Color

This phase has two surface contexts: **light screens** (SafetyMount, WalkingDirections) and **map overlay** (NavigateToBike, EndRideFindCharging, RidingToCharging). Both use DSColors from `src/theme/theme.ts`.

### Light Screen Context (SafetyMount, WalkingDirections)

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` — DSColors.background | Screen background, card fill on WalkingDirections |
| Secondary (30%) | `#FAFAFA` — DSColors.surface | Checklist item row background (resting), step row background |
| Accent (10%) | `#C6FF2D` — DSColors.primary | "Start Ride" PrimaryButton background only |
| Accent text | `#0F0F0F` — DSColors.textOnPrimary | Text ON Electric Green button (mandatory — green is light 1.36:1) |
| Accessible green | `#7D9220` — DSColors.accent | Checked checklist item label color, "Active" status text |
| Destructive | `#D32F2F` — DSColors.error | Not used in this phase |

Accent (#C6FF2D) reserved for: PrimaryButton background ("Start Ride", "Navigate Here"). Never used as text color on white surfaces.

### Map Overlay Context (NavigateToBike, EndRideFindCharging, RidingToCharging)

| Role | Value | Usage |
|------|-------|-------|
| Map base | react-native-maps default | Fills full screen (StyleSheet.absoluteFill) |
| Overlay card | `rgba(15,15,15,0.85)` | ETA floating card background — matches ActiveRideScreen pattern |
| Overlay text primary | `#FFFFFF` | Bike/charger name, walk time on ETA card |
| Overlay text secondary | `#999999` | Distance label ("620 m") on ETA card |
| Polyline | `#C6FF2D` — DSColors.primary | Route line on map, strokeWidth 4 |
| User dot marker | `#FFFFFF` fill + `#C6FF2D` border | 16dp circle, borderWidth 3 — matches ActiveRideScreen userMarker |
| Charger pin marker | `#C6FF2D` fill | ev-station icon, MaterialCommunityIcons, 24dp |
| Info card background | `#FFFFFF` — DSColors.background | Charger tap info card (EndRideFindCharging) |
| Info card border | `#EBEBEB` — DSColors.border | Card border-radius 12, borderWidth 1 |

Border token: `#EBEBEB` — DSColors.border — used for checklist item separators, info card outline.

## Screens

### 1. NavigateToBike

**Requirements:** NAV-01 | **Plan:** 07-01

**Layout:**
- Root: `View` with `StyleSheet.absoluteFill` (same as ActiveRideScreen, MapScreen)
- Layer 1 (bottom): `MapView` with `StyleSheet.absoluteFill`, `scrollEnabled: false`, `zoomEnabled: true`, `rotateEnabled: false`, `pitchEnabled: false`
- Layer 2: `<Polyline>` from react-native-maps — 3–4 hardcoded waypoints, `strokeColor: '#C6FF2D'`, `strokeWidth: 4`
- Layer 3 (top): ETA floating card, `position: 'absolute'`, `top: insets.top + 8`, `left: 16`, `right: 16`
- Layer 4 (bottom): "View Turn-by-Turn" secondary button, `position: 'absolute'`, `bottom: insets.bottom + 16`, `left: 16`, `right: 16`

**ETA Card anatomy:**
```
[ Bike name (headingMd / white)          ]
[ X min walk (label / white)  —  Y m (label / textSecondary) ]
[ ─────────────────────────────────────── ]
[ [View Turn-by-Turn]  (secondary button) ]
```
- Card: `backgroundColor: 'rgba(15,15,15,0.85)'`, `borderRadius: 16`, `paddingHorizontal: 24`, `paddingVertical: 16`
- "View Turn-by-Turn" button: `TouchableOpacity`, `borderWidth: 1`, `borderColor: 'rgba(255,255,255,0.3)'`, `borderRadius: 8`, `paddingVertical: 10`, label 15dp / 500 / white
- On press: `navigation.push('WalkingDirections', { bike })`

**Map markers:**
- User dot: 16dp circle, fill `#FFFFFF`, border 3dp `#C6FF2D`
- Bike destination pin: `MaterialCommunityIcons` `bicycle` icon, 24dp, color `#C6FF2D`

**Mock data:**
- User position: `{ latitude: 52.3676, longitude: 4.9041 }` (Amsterdam fallback)
- Bike position: use `bike.latitude` / `bike.longitude` from route params
- Polyline waypoints: 3 intermediate coords between user and bike (choose plausible Amsterdam street points)
- ETA: `Math.round(haversineKm(userLat, userLon, bike.latitude, bike.longitude) / 5 * 60)` minutes
- Distance: `Math.round(haversineKm(...) * 1000)` meters

**States:**
- Loading (location resolving): `ActivityIndicator` size large, color `#C6FF2D`, centered on `#FFFFFF` background
- Ready: Map + ETA card + polyline visible
- No state errors (mock data always resolves)

**Navigation:** `NavStack` modal (presentation: 'modal', headerShown: false on stack). No back button in ETA card — user swipes down to dismiss modal.

### 2. WalkingDirections

**Requirements:** NAV-02 | **Plan:** 07-01

**Layout:**
- Root: `SafeAreaView` with `flex: 1`, `backgroundColor: DSColors.background`
- Custom header row (matches LoginSecurityScreen pattern)
- `FlatList` of 3–5 step rows, `contentContainerStyle: { paddingHorizontal: 16, paddingTop: 8 }`

**Custom header:**
```
[ arrow-left (24dp / textPrimary) ]  [ Walking Directions (headingMd / textPrimary) ]  [ spacer width:40 ]
```
- `flexDirection: 'row'`, `alignItems: 'center'`, `justifyContent: 'space-between'`
- `paddingHorizontal: 16`, `paddingVertical: 12`
- `borderBottomWidth: 1`, `borderBottomColor: DSColors.border`
- Back press: `navigation.goBack()` (returns to NavigateToBike)

**Step row anatomy:**
```
[ icon (24dp / textPrimary) ]  [ Step text (body / textPrimary) ]  [ distance (label / textSecondary) ]
```
- Row: `flexDirection: 'row'`, `alignItems: 'center'`, `gap: 12`, `paddingVertical: 16`, `borderBottomWidth: 1`, `borderBottomColor: DSColors.border`
- Icon column: fixed `width: 32`
- Step text column: `flex: 1`
- Distance column: fixed `minWidth: 48`, `textAlign: 'right'`

**Direction icons (MaterialCommunityIcons):**
| Step type | Icon name | Notes |
|-----------|-----------|-------|
| Straight / head north | `arrow-up` | First step |
| Turn left | `arrow-left` | Left turns |
| Turn right | `arrow-right` | Right turns |
| Turn left-back | `arrow-left-bottom` | Sharp left |
| Arrival | `flag-checkered` | Final step, color: DSColors.primary |

**Mock steps (Amsterdam-flavored):**
1. `arrow-up` — "Head north on Damrak" — 150 m
2. `arrow-left` — "Turn left onto Nieuwendijk" — 200 m
3. `arrow-up` — "Continue straight for 200 m" — 200 m
4. `arrow-right` — "Turn right onto Warmoesstraat" — 120 m
5. `flag-checkered` — "Arrive at your bike — right side of the street" — 0 m (arrival icon in `#C6FF2D`)

**States:** No empty state (mock steps always present). No error state.

### 3. SafetyMount

**Requirements:** RIDE-05 | **Plan:** 07-02

**Layout:**
- Root: `SafeAreaView` with `flex: 1`, `backgroundColor: DSColors.background`
- Custom header
- `ScrollView` with `contentContainerStyle: { paddingHorizontal: 16, paddingTop: 16, paddingBottom: 32 }`
- Checklist section
- Spacer (`flex: 1`)
- "Start Ride" `PrimaryButton` pinned in scroll content bottom (not absolutely positioned — inside ScrollView)

**Custom header:**
```
[ arrow-left (24dp / textPrimary) ]  [ Safety Check (headingMd / textPrimary) ]  [ spacer width:40 ]
```
- Same header pattern as LoginSecurityScreen / WalkingDirections
- Back press: `navigation.goBack()` (returns to UnlockSuccessScreen — pops RideStack back)

**Section subtitle (below header, inside scroll):**
- "Complete all checks before starting your ride"
- Style: `body / textSecondary`, `marginBottom: 24`

**Checklist items (4 items, state: unchecked → checked):**

| # | Label | Icon (unchecked) | Icon (checked) |
|---|-------|------------------|----------------|
| 1 | Helmet secured | `helmet` (textSecondary) | `helmet` (accent #7D9220) |
| 2 | Brakes tested | `car-brake-hold` (textSecondary) | `car-brake-hold` (accent) |
| 3 | Lights working | `lightbulb-on` (textSecondary) | `lightbulb-on` (accent) |
| 4 | App tracking active | `map-marker-check` (textSecondary) | `map-marker-check` (accent) |

**Checklist row anatomy:**
```
[ icon 24dp ]  [ label (body / textPrimary) ]  [ check-circle OR circle-outline 24dp ]
```
- Row: `flexDirection: 'row'`, `alignItems: 'center'`, `paddingVertical: 16`, `gap: 12`
- `borderBottomWidth: 1`, `borderBottomColor: DSColors.border`
- Unchecked: left icon color `textSecondary`, right icon `circle-outline` color `DSColors.border`
- Checked: left icon color `DSColors.accent` (#7D9220), right icon `check-circle` color `DSColors.accent`
- Label color: always `textPrimary` (no strike-through)
- Entire row is `TouchableOpacity` (`activeOpacity: 0.7`) — tap toggles checked state

**"Start Ride" button:**
- Component: `PrimaryButton` with `disabled` prop
- Disabled until all 4 items checked: `disabled={checkedCount < 4}`
- Label: "Start Ride"
- Disabled visual: opacity 0.4 (PrimaryButton's existing disabled style)
- On press (all checked): `navigation.navigate('ActiveRide', { bike })` (within RideStack)
- `marginTop: 32`

**States:**
- Initial: all 4 unchecked, "Start Ride" disabled
- Partial: 1–3 checked, "Start Ride" still disabled
- All checked: "Start Ride" enabled (Electric Green background, black label)

**Copy:**
- Screen title: "Safety Check"
- Subtitle: "Complete all checks before starting your ride"
- Button: "Start Ride"

### 4. EndRideFindCharging

**Requirements:** RIDE-06 | **Plan:** 07-03

**Layout:**
- Root: `View` with `StyleSheet.absoluteFill`
- Layer 1: `MapView` with `StyleSheet.absoluteFill`, `scrollEnabled: true`, `zoomEnabled: true`
- Layer 2: Charger `Marker` components (3–5 pins)
- Layer 3 (top): close button or modal dismiss indicator (top-left back chevron, `position: 'absolute'`, `top: insets.top + 8`, `left: 16`)
- Layer 4 (conditional): charger info card, shown when a charger pin is tapped

**Map center:** User's last known location — `{ latitude: 52.3676, longitude: 4.9041 }` (Amsterdam fallback). `latitudeDelta: 0.02`, `longitudeDelta: 0.02` (tighter zoom than bike discovery).

**Charger pins:**
- Icon: `MaterialCommunityIcons` `ev-station`, 28dp, color `#C6FF2D` (Electric Green)
- Marker: custom `View` wrapper — circular 40dp badge, `backgroundColor: DSColors.background`, `borderWidth: 2`, `borderColor: DSColors.primary`, `borderRadius: 20`
- `tracksViewChanges: false`

**Mock charger stations (Amsterdam):**
| Name | Latitude | Longitude |
|------|----------|-----------|
| VoltHub Central | 52.3731 | 4.8936 |
| Dam Square Charger | 52.3728 | 4.8936 |
| Waterlooplein Station | 52.3678 | 4.9006 |
| Leidseplein EV Point | 52.3638 | 4.8831 |
| Vondelpark Charge Bay | 52.3580 | 4.8688 |

**Charger info card (shown on pin tap):**
```
[ charger name (headingMd / textPrimary) ]
[ distance label (label / textSecondary)  ]
[ [Navigate Here] PrimaryButton           ]
```
- Card: `position: 'absolute'`, `bottom: insets.bottom + 16`, `left: 16`, `right: 16`
- `backgroundColor: DSColors.background`, `borderRadius: 16`, `padding: 16`
- `borderWidth: 1`, `borderColor: DSColors.border`
- Shadow: `elevation: 4` (Android) / `shadowColor: '#000'` etc.
- Distance: `Math.round(haversineKm(userLat, userLon, charger.latitude, charger.longitude) * 1000)` meters, displayed as "Y m away"
- "Navigate Here" button: `PrimaryButton` label, on press: `navigation.push('RidingToCharging', { chargerName: charger.name, location: { latitude: charger.latitude, longitude: charger.longitude } })`

**Close button (top-left):**
- `MaterialCommunityIcons` `close` icon, 24dp, `textPrimary`
- Wrapped in `TouchableOpacity`, 44dp touch target
- `backgroundColor: 'rgba(255,255,255,0.9)'`, `borderRadius: 20`, padding 8dp
- On press: dismiss ChargeStack (`navigation.getParent()?.goBack()`)

**States:**
- Default: map centered on user, all charger pins visible, no info card
- Pin tapped: info card appears at bottom for selected charger
- Tapping another pin: info card updates to new charger (no dismiss animation needed)
- Tapping map (empty area): info card hides

**Empty state:** Not applicable (mock chargers always present).

### 5. RidingToCharging

**Requirements:** RIDE-07 | **Plan:** 07-03

**Layout:** Identical pattern to NavigateToBike. Same component structure.

- Root: `View` with `StyleSheet.absoluteFill`
- Layer 1: `MapView` `StyleSheet.absoluteFill`, `scrollEnabled: false`
- Layer 2: `<Polyline>` — hardcoded waypoints from user location to charger, `strokeColor: '#C6FF2D'`, `strokeWidth: 4`
- Layer 3: ETA floating card, `top: insets.top + 8`, `left: 16`, `right: 16`

**ETA card content:**
```
[ Charger name (headingMd / white)                    ]
[ X min walk (label / white)  —  Y m (label / secondary) ]
```
- Card: `backgroundColor: 'rgba(15,15,15,0.85)'`, `borderRadius: 16`, `paddingHorizontal: 24`, `paddingVertical: 16`
- No secondary action button (charger navigation is final destination — no deeper drill)
- ETA: same formula as NavigateToBike (`haversineKm / 5 * 60`)

**Map markers:**
- User dot: 16dp circle, fill `#FFFFFF`, border 3dp `#C6FF2D`
- Charger destination: `MaterialCommunityIcons` `ev-station`, 28dp, color `#C6FF2D`

**Navigation:** Part of `ChargeStack` modal. No explicit back button (swipe down to dismiss ChargeStack).
