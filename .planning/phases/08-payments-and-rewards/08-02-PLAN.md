## Phase Goal

**As a** tourist, **I want to** add and choose my payment method before confirming a ride payment, **so that** I can pay with a card I trust and see the correct card label at checkout.

<objective>

Purpose: PAY-05 (add payment method) and PAY-06 (select payment method at checkout) together deliver a complete user journey: add a card → see it in the list → select it as default → see it reflected in the payment summary.
Output: Two new screens + two updated screens fully wired through paymentService.
</objective>

    State:
    - cardNumber: string (display value with spaces, e.g. "4242 4242 4242 4242")
    - expiry: string (MM/YY format)

    - cardholderName: string
    - touched: { cardNumber: boolean, expiry: boolean, cvv: boolean, cardholderName: boolean } (all start false)

    Helper functions (defined outside component):
    - formatCardNumber(raw: string): string — strips non-digits, slices to 16 chars, groups into blocks of 4 joined by spaces
    - formatExpiry(raw: string): string — strips non-digits, slices to 4 chars, if length >= 3 returns slice(0,2) + '/' + slice(2), else returns digits
    - detectBrand(digits: string): string — if starts with '4' returns 'Visa', if starts with '5' returns 'Mastercard', else returns 'Card'

    Validation functions (return error string or undefined):
    - validateCardNumber(val: string): string | undefined — strip spaces; if digits.length !== 16 return 'Card number must be 16 digits'
    - validateExpiry(val: string): string | undefined — if doesn't match /^\d{2}\/\d{2}$/ return 'Enter a valid expiry (MM/YY)'
    - validateCvv(val: string): string | undefined — strip non-digits; if length < 3 or > 4 return 'CVV must be 3–4 digits'
    - validateName(val: string): string | undefined — if val.trim().length === 0 return 'Cardholder name is required'

    isFormValid: boolean — derived from all four validators returning undefined.

    handleSave: strips spaces from cardNumber to get rawDigits, calls paymentService.addCard({ last4: rawDigits.slice(-4), brand: detectBrand(rawDigits), expiry, cardholderName }) then calls navigation.goBack().

    On Save button press when NOT isFormValid: set all touched fields to true (surface all errors at once), do not call handleSave.

    Layout (StyleSheet.create + DSColors, no NativeWind):
    - SafeAreaView edges={['bottom']} wrapping root
    - Custom header: View row with TouchableOpacity (arrow-left, goBack) + Text "Add Payment Method" + View width:40
    - ScrollView with paddingHorizontal:24 contentContainerStyle, paddingBottom:32
    - Section label "CARD DETAILS" (sectionHeader style matching PaymentMethodsScreen sectionHeader)
    - Four FormField components in order: Card Number (keyboardType='number-pad'), Expiry (keyboardType='number-pad', placeholder 'MM/YY'), CVV (keyboardType='number-pad', secureTextEntry), Cardholder Name (autoCapitalize='words')
    - onChangeText for Card Number: setCardNumber(formatCardNumber(text))
    - onChangeText for Expiry: setExpiry(formatExpiry(text))
    - onBlur for each: set touched[field] = true
    - error prop for each: touched[field] ? validateXxx(value) : undefined
    - PrimaryButton label="Save Card" onPress handler: if isFormValid call handleSave; else force all touched true
    - disabled prop on PrimaryButton: false always (button is always pressable; pressing when invalid surfaces errors per above)
    - Bottom padding on ScrollView so Save CTA is accessible above keyboard
