# Phase 9 — UI Design Contract

> Visual and interaction contract for Phase 9: Discovery & Content.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> All decisions sourced from 09-CONTEXT.md (D-01–D-15) unless noted otherwise.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (React Native Paper + NativeWind not applicable here) |
| Preset | not applicable |
| Component library | React Native Paper (MD3LightTheme extended) |
| Icon library | MaterialCommunityIcons (@expo/vector-icons) |
| Font | Inter (body/interface) + Manjari (display/brand) — system fallback until @expo-google-fonts loaded |

**Styling rule (non-negotiable):** All Phase 9 screens use `StyleSheet.create` + `DSColors` from `src/theme/theme.ts`. NativeWind classes are NOT used on any screen — this is established project convention for all complex/map screens and all prior phases.

**Token source:** `VoltVenture/src/theme/theme.ts` — `DSColors` and `DSTypography` objects. Values must be consumed directly; do not re-declare hex literals inline.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline margin, handle dot |
| sm | 8px | Chip gap, bottom sheet handle margin-top, item separator height |
| md | 16px | Default horizontal/vertical padding, row paddingVertical |
| lg | 24px | Screen horizontal padding (all screens), section header padding, bottom sheet paddingHorizontal |
| xl | 32px | Bottom sheet paddingBottom, card bottom margin |
| 2xl | 48px | Major section vertical breaks |
| 3xl | 64px | Page-level top/bottom breathing room on legal screens |

Exceptions:
- Menu row gap between icon and label: 12px (matches AccountScreen.tsx exactly — not a multiple of 4, inherited from existing pattern)
- Bottom sheet handle: width 40px, height 4px, borderRadius 2px (matches BikeDetailSheet.tsx)
- Avatar/touch targets: 48px minimum height for all interactive rows

## Typography

| Role | Token | Size | Weight | Line Height | Usage |
|------|-------|------|--------|-------------|-------|
| Display | `DSTypography.display` | 32px | 700 | 36px | Screen hero numbers (not used in Phase 9) |

## Color

All hex values sourced from `DSColors` in `src/theme/theme.ts`. Do not inline hex literals.

| Role | DSColors Token | Hex | Usage |
|------|---------------|-----|-------|
| Dominant (60%) | `DSColors.background` | #FFFFFF | All screen backgrounds, ScrollView background, FlatList background |
| Secondary (30%) | `DSColors.surface` | #FAFAFA | Menu rows (DiscoverScreen), hub card background, bottom sheet surface, FAQ accordion surface |
| Accent (10%) | `DSColors.primary` | #C6FF2D | "Get Directions" PrimaryButton background, active tab indicator for Discover tab, VIP hub map pin background |
| Accent accessible (text) | `DSColors.accent` | #7D9220 | "Available" status badge text on white surface (4.6:1, AA-compliant) |
| Text primary | `DSColors.textPrimary` | #0F0F0F | All primary labels, row labels, heading text, FAQ question text |
| Text secondary | `DSColors.textSecondary` | #808080 | Subtitle text, café hours, hub distance, chevron icons, section overline headers |
| Border | `DSColors.border` | #EBEBEB | Row separators, bottom sheet handle, card borders, sheet drag indicator |
| Destructive | `DSColors.destructive` | #B00020 | Not used in Phase 9 — no destructive actions |
| Text on primary | `DSColors.textOnPrimary` | #0F0F0F | Button label on PrimaryButton (green bg), text on Electric Green backgrounds |

**Critical contrast rule:** `DSColors.primary` (#C6FF2D) is a LIGHT color (1.36:1 contrast on white). It is NEVER used as text color on light surfaces. It is used only as a background (button fill, map pin fill, active tab indicator).

Accent reserved for:
- PrimaryButton background ("Get Directions" in CafeDetailSheet, "Get Directions" in VipHubs expanded card)
- Discover tab bottom indicator (active state)
- VIP hub map pin circle fill
- "Available" status badge background tint (light: `rgba(198,255,45,0.15)` with `DSColors.accent` text)

Difficulty badge colors (declared inline — not in DSColors):
- Easy: background `rgba(125,146,32,0.12)`, text `DSColors.accent` (#7D9220) — green, AA on white
- Moderate: background `rgba(255,152,0,0.12)`, text `#E65100` — amber, AA on white
- Challenging: background `rgba(176,0,32,0.12)`, text `DSColors.destructive` (#B00020) — red, AA on white

VIP hub status badge colors:
- Available: background `rgba(125,146,32,0.12)`, text `DSColors.accent` — same as Easy difficulty
- Full: background `rgba(176,0,32,0.12)`, text `DSColors.destructive` — same as Challenging

## Screen-by-Screen Interaction Contract

### 1. Discover Tab (AppTabs addition)

- Tab position: 3rd tab (Map | Discover | Account). Discover in the middle.
- Tab icon active: `compass` (MaterialCommunityIcons)
- Tab icon inactive: `compass-outline` (MaterialCommunityIcons)
- Tab label: "Discover"
- Tab bar style: inherits existing AppTabs styling — active indicator `DSColors.primary`
- Source: D-01

### 2. DiscoverScreen (Discover home)

**Layout:** SafeAreaView > ScrollView (or static View if content fits without scroll)

**Structure:**
- Screen title: "Discover" — 24px, weight 700, `DSColors.textPrimary`, paddingHorizontal 24, paddingTop 24, paddingBottom 16 (matches AccountScreen `title` style exactly)
- Section header "EXPLORE": uppercase, 12px, weight 500, `DSColors.textSecondary`, letterSpacing 0.8, paddingHorizontal 24, paddingTop 16, paddingBottom 8
- Menu rows (Explore section): "Curated Routes" (`map-route` icon), "VIP Hubs" (`lightning-bolt-circle` icon)
- Section header "INFO": uppercase, 12px, weight 500, `DSColors.textSecondary`, letterSpacing 0.8, paddingHorizontal 24, paddingTop 16, paddingBottom 8
- Menu rows (Info section): "Support & Help" (`help-circle-outline` icon), "Privacy Policy" (`file-document-outline` icon), "Terms of Service" (`file-check-outline` icon)

**Menu row spec (identical to AccountScreen `menuRow` style):**
- flexDirection: row, alignItems: center, justifyContent: space-between
- paddingHorizontal: 24, paddingVertical: 16
- backgroundColor: `DSColors.surface`
- borderTopWidth: 1, borderColor: `DSColors.border`
- Last row in each section also gets borderBottomWidth: 1
- Left side: icon (size 20, color `DSColors.textPrimary`) + label (gap: 12)
- Right side: `chevron-right` (size 20, color `DSColors.textSecondary`)
- Label: 16px, weight 400, `DSColors.textPrimary`

**Interactions:** Each row tap navigates to respective DiscoverStack screen. activeOpacity: 0.7 on all TouchableOpacity rows.

**Accessibility:** accessibilityRole="button" on each TouchableOpacity row.
- Source: D-01, D-02, D-03

### 4. VipHubsScreen

**Layout:** SafeAreaView > custom header + View with fixed split layout

**Custom header:** Same spec as CuratedRoutesScreen, title: "VIP Hubs"

**Split layout (no scroll on outer container — inner FlatList scrolls):**
- MapView: height = 45% of available screen height (use `Dimensions.get('window').height × 0.45` minus header height, approximately 300–320dp on most phones). Use StyleSheet.create fixed height — NOT flex fraction, per Claude's Discretion.
- FlatList: flex: 1 (takes remaining 55%)

**MapView spec:**
- Non-interactive: `scrollEnabled={false}`, `zoomEnabled={false}`, `pitchEnabled={false}`, `rotateEnabled={false}`
- Initial region: Amsterdam center (52.3676°N, 4.9041°E), latitudeDelta: 0.04, longitudeDelta: 0.04
- Hub pins: VIP hub marker component (see marker spec below)
- Tapping a hub pin: scrolls FlatList to that hub's card index (`flatListRef.current?.scrollToIndex`) and expands it

**VIP hub marker spec:**
- Circle: width 36, height 36, borderRadius 18
- backgroundColor: `DSColors.primary` (#C6FF2D) — distinct from bike pins (same color but different icon) and café pins (white)
- borderWidth: 2, borderColor: `DSColors.textOnPrimary`
- Icon: `star-circle` (MaterialCommunityIcons), size 18, color `DSColors.textOnPrimary` (#0F0F0F)
- Tail: same triangle tail shape as BikeMarker — borderTopColor: `DSColors.primary`
- Note: VIP hub uses `star-circle` while BikeMarker uses `lightning-bolt` — visually distinct by icon

**Hub card (FlatList item) — collapsed state:**
- backgroundColor: `DSColors.surface`, borderRadius: 12, borderWidth: 1, borderColor: `DSColors.border`
- padding: 16, marginHorizontal: 16, marginVertical: 6
- Row 1: Hub name (17px, weight 600, `DSColors.textPrimary`) + "VIP" badge (right-aligned)
- Row 2: Distance from user (15px, weight 400, `DSColors.textSecondary`, `map-marker` icon) + Status badge (right-aligned)
- Tap to expand

**"VIP" badge:**
- backgroundColor: `DSColors.primary` (#C6FF2D), color: `DSColors.textOnPrimary` (#0F0F0F)
- borderRadius: 4, paddingHorizontal: 6, paddingVertical: 2
- fontSize: 11, fontWeight: '600'

**Hub card — expanded state (inline expand, no new screen):**
- Appended below collapsed content with 12px top margin
- Description paragraph: 15px, weight 400, `DSColors.textPrimary`, lineHeight 22
- Amenities list (3 items with `check-circle` icon, `DSColors.accent`, size 16):
  - "Fast charging (up to 80% in 45 min)"
  - "Covered, secure parking"
  - "24h access — no closing time"
- Operating hours: `clock-outline` icon + hours text, 15px, `DSColors.textSecondary`
- "Get Directions" PrimaryButton: full-width, marginTop 16, navigates to NavigateToPoi with hub name and coordinates
- Collapse: tapping the expanded card (or a "Close" affordance) collapses it back

**Tapping a list card:** Focuses MapView on that hub pin (animateToRegion). Expands/collapses the card inline.

**Mock data (5 VIP hubs):**

### 6. NavigateToPoi screen

**Identical structure to NavigateToBikeScreen** (Phase 7 — D-10, D-11, D-12 from 07-CONTEXT.md).

Differences from NavigateToBike:
- Route params: `{ name: string; location: { latitude: number; longitude: number } }` instead of `{ bike: Bike }`
- ETA card displays `name` where NavigateToBike displayed `bike.name`
- Distance/ETA computed with same `haversineKm` formula
- "View Turn-by-Turn" button is absent (NavigateToPoi does not push to WalkingDirections — café/hub directions are point-to-point only, no step list screen)

**MapView:** Full screen, StyleSheet.create, non-interactive during navigation (`scrollEnabled={false}`)

**ETA card (floating, pinned top):**
- backgroundColor: `rgba(15,15,15,0.85)` (semi-transparent dark — same as ActiveRide overlay)
- borderRadius: 12, padding: 16, marginHorizontal: 16, marginTop: 16
- Destination name: 17px, weight 600, color: #FFFFFF
- ETA line: `Math.round(haversineKm / 5 × 60)` min + `(haversineKm × 1000).toFixed(0)` m — format "8 min walk — 620 m"
- ETA text: 15px, weight 400, color: rgba(255,255,255,0.75)

**Polyline:** `strokeColor: DSColors.primary` (#C6FF2D), `strokeWidth: 4` — same spec as Phase 7

**Custom header:** `headerShown: false` — ETA card is the only header element (full-screen map)

**Back navigation:** Back button inside ETA card — `arrow-left` icon, white, 24×24, dismisses to previous screen

- Source: D-06, 07-CONTEXT.md D-10, D-11, D-12

### 8. PrivacyPolicyScreen

**Layout:** SafeAreaView > custom header + ScrollView

**Custom header:** same spec, title: "Privacy Policy"

**ScrollView contentContainerStyle:** paddingHorizontal 24, paddingTop 24, paddingBottom 64

**Structure:** 4 sections, each with a section header + 1–2 paragraphs

Section header style: 17px, weight 600, `DSColors.textPrimary`, marginBottom 8, marginTop 24 (except first section: marginTop 0)

Paragraph style: 15px, weight 400, `DSColors.textPrimary`, lineHeight 22, marginBottom 12

**Section 1 — "Data We Collect"**
VoltVenture collects information you provide when creating an account (name, email address), payment details processed securely through our payment provider, and location data while the app is in use to display nearby bikes and calculate ride distances.

We also collect device information (device model, OS version) and usage data (screens viewed, session duration) to improve app performance and identify issues.

**Section 2 — "How We Use Your Data"**
Your data is used to provide and improve the VoltVenture service, process payments, display nearby bikes on the map, calculate ride costs and distances, and send optional promotional communications (if you have opted in via Notification Preferences).

We do not sell your personal data to third parties. Anonymised aggregate data may be shared with municipal partners to improve cycling infrastructure planning.

**Section 3 — "Your Rights (GDPR)"**
Under the General Data Protection Regulation (GDPR), you have the right to access, correct, or delete your personal data at any time. You may also restrict or object to certain processing activities and request data portability.

To exercise these rights, contact our Data Protection Officer at privacy@voltventure.app. We will respond within 30 days.

**Section 4 — "Data Retention"**
Account data is retained for as long as your account is active. Ride history is retained for 24 months for billing and dispute purposes. If you delete your account, personal data is removed within 30 days, except where retention is required by law (e.g., financial records retained for 7 years per EU accounting regulations).
