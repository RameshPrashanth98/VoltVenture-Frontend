# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: Emulator-first — `npx expo run:android` fails if emulator is not running. Always start emulator and confirm `adb devices` shows `device` first.
- [ ] CONSTRAINT: android/ is gitignored — Any `expo prebuild --clean` wipes gradle.properties fixes. Reapply both fixes (JVM heap + newArchEnabled=false) after every clean prebuild.
- [ ] CONSTRAINT: newArchEnabled=false required — react-native-worklets + react-native-screens CMake config fails with JDK 17/21. Do NOT re-enable New Architecture without first installing a compatible CMake via Android Studio SDK Manager.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| expo-before-emulator | Running `npx expo run:android` before emulator is fully booted fails immediately | blocking | Always run `adb devices` and confirm `device` status before any expo build/run command |
| Insufficient JVM heap | Default -Xmx768m causes OutOfMemoryError: Metaspace during Gradle build with many RN native modules | blocking | Ensure android/gradle.properties has -Xmx4g -XX:MaxMetaspaceSize=512m before building |
| New Architecture + old CMake | newArchEnabled=true triggers CMake builds for react-native-worklets/screens; fails with JDK 17/21 restricted System methods | blocking | Keep newArchEnabled=false for UAT; only enable after verifying CMake 3.22.1+ is installed |
