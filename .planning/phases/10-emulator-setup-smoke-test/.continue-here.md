**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| expo-before-emulator | Running `npx expo run:android` before emulator is fully booted fails immediately | blocking | Always run `adb devices` and confirm `device` status before any expo build/run command |
| Insufficient JVM heap | Default -Xmx768m causes OutOfMemoryError: Metaspace during Gradle build with many RN native modules | blocking | Ensure android/gradle.properties has -Xmx4g -XX:MaxMetaspaceSize=512m before building |
| New Architecture + old CMake | newArchEnabled=true triggers CMake builds for react-native-worklets/screens; fails with JDK 17/21 restricted System methods | blocking | Keep newArchEnabled=false for UAT; only enable after verifying CMake 3.22.1+ is installed |
