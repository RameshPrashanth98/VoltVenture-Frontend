# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: Emulator-first — `npx expo run:android` fails with "could not connect to TCP port 5554" if the emulator is not already running and at `device` state. Always start the emulator manually and confirm `adb devices` shows `device` before invoking any expo build command.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| expo-before-emulator | Running `npx expo run:android` before the emulator is fully booted causes an immediate connection failure (TCP 5554 refused). | blocking | Always run `adb devices` and confirm `device` status before any expo build/run command. |
