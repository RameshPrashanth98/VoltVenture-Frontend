## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Build from D:\ | CMake path length limit (250 chars) — reanimated object paths exceed limit at D:\ long path | blocking | Always build from C:\vv |
| Android Studio open during build | 15 GB RAM exhausted: AS + emulator + Gradle(2g) + parallel clang++ | blocking | Close AS, keep emulator running standalone |
| ninja parallel clang++ jobs | Each C++20 file (Folly/JSI/Hermes headers) uses 500MB–1GB per clang++ process | blocking | Set CMAKE_BUILD_PARALLEL_LEVEL=1 |
| Stale .cxx cache from D:\ | Gradle build cache restores old D:\ paths; cmake regenerates at D:\ | blocking | If D:\ paths appear, delete C:\vv node_modules\react-native-reanimated\android\.cxx and react-native-worklets\android\.cxx then wipe D:\gradle\caches\build-cache-1 |
